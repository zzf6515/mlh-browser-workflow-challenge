# MLH Challenge 6: Teach an AI Bot a Browser Workflow
This project completes MLH Challenge 6: Teach Grok Bot a Browser Workflow.
We built an AI Agent (Hermes Agent) with computer-use capability to perform browser automation workflow.

## Project Description
The agent can automatically launch the browser, visit the static website example.com, wait for page load, extract page title and main text content, and return the extracted result.
The workflow demonstrates AI Agent browser interaction capability.

## Technologies Used
- Hermes Agent
- AI Agent / Computer Use
- Browser Automation
- Local Large Language Model
